      Sobre o conversor

      O que este painel faz

      Converte materiais didáticos (em geral PDF) em Markdown acessível: texto estruturado com hierarquia de títulos, tabelas semânticas, descrição textual de imagens/diagramas e blocos de código identificados por linguagem e comentados — pronto para navegação fluida com leitor de tela (NVDA, VoiceOver, TalkBack).

      Como funciona

      1. Envio: os arquivos entram na fila de conversão.
      2. Extração: PDFs têm o texto extraído no navegador (mecanismo PDF.js). Tabelas são detectadas por posição; blocos de código, por padrões e fonte; páginas sem camada de texto são sinalizadas.
      3. Estruturação: o texto é organizado em Markdown com títulos, listas e blocos descritivos.
      4. Revisão: itens ambíguos (imagens, tabelas) ficam marcados como [REVER: …] para você descrever ou corrigir.
      5. Entrega: visualize, edite, salve no histórico e baixe o .md.

      Limitações conhecidas

      • PDF escaneado sem camada de texto não gera texto automaticamente — ele é sinalizado para tratamento manual (OCR) ou descrição.
      • A descrição de imagens/diagramas cobre o conteúdo visual; não é transcrição letra a letra de textos dentro de figuras.
      • Conversões ambíguas podem exigir ajuste pontual — por isso há o passo de revisão antes de salvar.
